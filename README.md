# Reply Challenge 2022



Our team's entry for the **Reply Code Challenge 2022**, an online team programming competition held in March 2022. We had a few hours to write programs that read the competition's input files and produced the best-scoring solutions.

## What's in here

The solutions live on each team member's branch:

| Branch | Author |
|---|---|
| `dickinsonalex` | Alex Dickinson |
| `chainfury` | Chainfury |
| `scot-survivor` | Scot-Survivor |
| `zomtato` | zomtato |

They include the input and output files, finding monster positions on the map and working through the task's challenges. `master` was cleared after the contest.
